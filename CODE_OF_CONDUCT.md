# Code of Conduct

This organization adopts the [Contributor Covenant, version 2.1][covenant], in full and without
modification, as the code of conduct for every repository here, including
willow-memory/willow-reconciler.

The canonical text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: participate in a way that would not embarrass you if quoted. Assume good faith,
disagree about the work rather than the person, and accept that maintainers may decline a
contribution without that being an insult.

## Scope

This applies in every space the organization controls — issues, pull requests, discussions,
commit messages, and code review across all repositories — and whenever someone is representing
the project in public.

## Reporting

Report unacceptable behavior to **[@rudi193-cmd](https://github.com/rudi193-cmd)** by opening a
private report through GitHub's **"Report a vulnerability"** form on this organization's
[`.github` Security tab][report]. Say plainly that it is a conduct report; it will not be
treated as a security matter.

[report]: https://github.com/willow-memory/.github/security/advisories/new

If the report concerns that maintainer, contact any other organization owner directly.

## Enforcement

Maintainers may take any action they judge proportionate, including editing or removing
contributions, and temporary or permanent bans from the organization. The Contributor Covenant's
enforcement guidelines describe the ladder that is normally followed.
